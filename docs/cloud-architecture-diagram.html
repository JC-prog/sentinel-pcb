Known gaps — deliberate, per infra/production/README.md

  • Qdrant is not provisioned anywhere. Long-term memory and the embedded PCB-case store both depend on it; in production today they'd have nowhere to reach (the app degrades gracefully, so this fails silently rather than crashing — memory just never works).
  • No Ollama instance. The "Local LLM" option in Settings has no OLLAMA_BASE_URL to point at in production.
  • Chat image uploads are on local container disk, not S3 — fine at desired_count = 1, breaks the moment the backend scales to more than one task.
  • No autoscaling anywhere — backend, inference, and litellm all run a single Fargate task.
  • No custom domain or ACM certificate — CloudFront and the ALB sit on their default AWS domains.
  • LiteLLM is master-key-only — the backend and any shared team proxy share one key; no per-consumer budgets yet.
